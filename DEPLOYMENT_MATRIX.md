# DSH Cross-OS Deployment Matrix

**Effort Tracking**: Portable DSH deployment from E:/ secondary drive (Windows 10) to multiple operating systems

---

## Deployment Matrix

| Aspect | Windows 10 | macOS (Intel/ARM) | Linux (Debian/Ubuntu) | Linux (Alpine/RHEL) |
|--------|-----------|------------------|----------------------|-------------------|
| **Primary Mount** | E:/ (second drive) | /Volumes/DSH-E or ~/dsh-e | /mnt/dsh-e or ~/dsh-e | /mnt/dsh-e or ~/dsh-e |
| **Path Pattern** | e:\path\to\file | /Volumes/DSH-E/path/to/file | /mnt/dsh-e/path/to/file | /mnt/dsh-e/path/to/file |
| **Node.js** | ^22.19 or >=24 | ^22.19 or >=24 | ^22.19 or >=24 | ^22.19 or >=24 |
| **Package Manager** | pnpm | pnpm | pnpm | pnpm |
| **Shell** | PowerShell 7 / bash | zsh / bash | bash | bash / sh |
| **Git** | git for Windows | Xcode git / homebrew | apt-get / yum | pkg / apk / yum |
| **pnpm Cache** | .pnpm-store-win/ | .pnpm-store-macos/ | .pnpm-store-linux/ | .pnpm-store-linux/ |
| **Native Build** | node-gyp + MSVC | node-gyp + clang | node-gyp + gcc | node-gyp + gcc/clang |
| **Landlock (Linux)** | N/A | N/A | native/landlock-run | native/landlock-run |
| **Setup Time** | ~10-15 min | ~8-12 min | ~8-12 min | ~5-10 min |

## Shared Configuration (Version-Controlled)

These files travel with the E:/ drive setup and require **no modification** across platforms:

### Must-Track Files
```
✓ computer_control_mcp.py    # MCP server setup (pure Python)
✓ mcp.json                    # MCP config (OS-agnostic JSON)
✓ pnpm-lock.yaml              # Dependency lock (reproducible)
✓ SETUP_E_DRIVE.md            # Setup documentation
✓ DEPLOYMENT_MATRIX.md        # This file
```

### OS-Specific Ignored (Regenerated Per Platform)
```
✗ node_modules/               # Regenerated by: pnpm install
✗ lib/                        # Regenerated by: pnpm run build
✗ .pnpm-store-*/              # Platform-specific cache
✗ coverage/                   # Local test runs only
✗ python/**/__pycache__/      # Python 3.x bytecode
✗ apps/web/dist/              # Web build output
```

## Environment Detection Pattern

### Automatic Path Resolution
```javascript
// TypeScript/Node.js example for cross-OS paths
const path = require('path');

const DSH_ROOT = process.env.DSH_ROOT ||
  (process.platform === 'win32'
    ? 'e:\\Github - Repositories\\deepseek-harness'
    : process.platform === 'darwin'
      ? '/Volumes/DSH-E/Github - Repositories/deepseek-harness'
      : '/mnt/dsh-e/Github - Repositories/deepseek-harness'
  );

const CONFIG_PATH = path.join(DSH_ROOT, 'mcp.json');
const MCP_SERVER = path.join(DSH_ROOT, 'computer_control_mcp.py');
```

### Bash/Shell Example
```bash
#!/bin/bash

case "$(uname -s)" in
  MINGW64_NT*|MSYS_NT*)
    export DSH_ROOT="e:/Github - Repositories/deepseek-harness"
    ;;
  Darwin)
    export DSH_ROOT="/Volumes/DSH-E/Github - Repositories/deepseek-harness"
    ;;
  Linux*)
    export DSH_ROOT="/mnt/dsh-e/Github - Repositories/deepseek-harness"
    ;;
esac

cd "$DSH_ROOT"
pnpm install
pnpm run build
```

## Installation Flow per OS

### Windows 10 (Baseline)
```powershell
# 1. Mount/navigate to E:/ drive
cd e:\Github - Repositories\deepseek-harness

# 2. Verify Node.js
node --version  # Should be ^22.19 or >=24
pnpm --version  # Should be latest

# 3. Install dependencies
pnpm install

# 4. Validate setup
pnpm run typecheck
pnpm run test --run
pnpm run build

# 5. Test DSH
pnpm dsh --profile headless "test task"
```

### macOS (USB External Drive or Clone)
```bash
# 1. Mount external drive OR clone repository
# Option A: USB drive (simulating E:/)
# Finder → mounted drive → navigate to Github - Repositories/deepseek-harness

# Option B: Clone locally
git clone <repo-url> ~/dsh-workspace
cd ~/dsh-workspace

# 2. Install Node.js (if needed)
brew install node@latest  # or asdf/nvm

# 3. Install pnpm
brew install pnpm

# 4. Same installation flow
pnpm install
pnpm run typecheck
pnpm run test --run
pnpm run build
pnpm dsh --profile headless "test task"
```

### Linux - Debian/Ubuntu
```bash
# 1. Mount secondary drive
sudo mkdir -p /mnt/dsh-e
sudo mount /dev/sdX1 /mnt/dsh-e
# OR clone locally
git clone <repo-url> ~/dsh-workspace
cd ~/dsh-workspace

# 2. Install Node.js and pnpm
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
npm install -g pnpm

# 3. Installation flow
pnpm install
pnpm run typecheck
pnpm run test --run
pnpm run build
pnpm dsh --profile headless "test task"
```

### Linux - Alpine/Container
```dockerfile
FROM node:22-alpine

RUN npm install -g pnpm

WORKDIR /dsh

# Mount or copy E:/ directory contents
COPY . .

RUN pnpm install
RUN pnpm run build

ENTRYPOINT ["pnpm", "dsh", "--profile", "headless"]
```

## Configuration Migration Guide

### Step 1: Prepare Source (Windows 10)
```powershell
cd e:\Github - Repositories\deepseek-harness

# Verify tracked files
git ls-files | Select-String "computer_control_mcp.py|mcp.json|pnpm-lock.yaml"

# Commit any pending changes
git add .
git commit -m "Setup for cross-OS deployment from E:/ drive"
```

### Step 2: Target Platform
```bash
# Clone with full history
git clone --depth=1 <repo-url> ~/dsh-workspace
cd ~/dsh-workspace

# Restore platform-specific cache paths (optional)
mkdir -p .pnpm-store-linux
# OR
mkdir -p .pnpm-store-macos
```

### Step 3: Environment Setup
```bash
# Set environment variable for consistency
export DSH_ROOT="$(pwd)"

# Verify configuration files present
ls computer_control_mcp.py mcp.json

# Run installation
pnpm install
pnpm run build
```

## Troubleshooting by Platform

### Windows 10
| Issue | Solution |
|-------|----------|
| E:/ drive not found | Check Disk Management, ensure second drive is mounted |
| pnpm cache conflicts | `pnpm store prune` to clean .pnpm-store-win/ |
| Path with spaces issues | Use quotes: `cd "e:\GitHub - Repositories\dsh"` |
| PowerShell execution policy | `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned` |

### macOS
| Issue | Solution |
|-------|----------|
| External drive not showing | Finder → Devices → click mount, or `diskutil list` |
| Node version mismatch | `nvm install 22` or `asdf install nodejs 22.19` |
| Native build failures | `xcode-select --install` or upgrade Xcode |
| pnpm permission denied | `sudo chown -R $USER ~/.pnpm` |

### Linux
| Issue | Solution |
|-------|----------|
| Mount permissions | `sudo chown -R $USER /mnt/dsh-e` |
| Node not found | Use nvm: `nvm install 22` or system package manager |
| Build tool missing | Ubuntu: `sudo apt-get install build-essential python3` |
| SQLite errors | `sudo apt-get install libsqlite3-dev` |

## Performance Metrics

### Expected Installation Times (First Run)
- **Dependency Download**: 2-5 min (network dependent)
- **pnpm Install**: 3-8 min (pnpm-store population)
- **TypeScript Compile**: 1-2 min (lib/ generation)
- **Test Run**: 2-5 min (depends on coverage)
- **Total**: 8-20 min per platform

### Cache Performance (Subsequent Runs)
- **Warm pnpm cache**: ~30 sec (only new packages)
- **Incremental build**: ~20 sec (TypeScript incremental)
- **Test re-run**: ~2 min (faster with cache)

## Release Packaging Strategy

### For Distribution
```
deepseek-harness-{version}.tar.gz
├── README.md                        # Platform detection
├── SETUP_E_DRIVE.md                 # Setup guide
├── setup-{platform}.sh/ps1          # Platform installer
├── pnpm-lock.yaml                   # Locked dependencies
├── computer_control_mcp.py          # MCP server
├── mcp.json                         # MCP config
└── packages/...                     # Full source tree
```

### Automated Build Matrix (CI/CD)
```yaml
# GitHub Actions / similar
matrix:
  os: [windows-2022, macos-latest, ubuntu-latest]
  node-version: [22, 24]

steps:
  - uses: actions/checkout@v3
  - uses: actions/setup-node@v3
    with:
      node-version: ${{ matrix.node-version }}
  - run: npm install -g pnpm
  - run: pnpm install
  - run: pnpm run test
  - run: pnpm run build
  - uses: actions/upload-artifact@v3
    with:
      name: dsh-${{ runner.os }}-${{ matrix.node-version }}
```
