## Summary

Explore, inspect, and trigger the 140 integrated capabilities across life management, e-commerce arbitrage, financial autonomy, enterprise DevOps, growth marketing, AI multimodal infrastructure, and creative endeavors inside an interactive right-Sidebar tab.

## Model Experience

- **Interactive Discovery:** Users browse 140 capabilities grouped across 7 domains directly within the GUI.
- **Prompt Triggering:** Each capability card provides a quick-trigger action copying prompt templates into the composer.
- **Zero Invariant Divergence:** Relies entirely on client-side reactive stores and Cordis slots.
