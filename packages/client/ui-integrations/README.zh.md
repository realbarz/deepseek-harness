# @deepseek-ai/dsh-client-ui-integrations

[English](README.md) | 中文

## 概述

在右侧边栏交互式标签页中探索、检查并触发覆盖生活管理、电商套利、资产自主、企业研发、增长营销、AI多模态底座与创意套件的 140 项全栈集成能力。

## 模型体验

- **交互式发现：** 用户可以在图形界面中直观浏览划分为 7 大领域的 140 项能力。
- **提示词触发：** 每个能力卡片均提供一键快捷操作，将任务提示词复制并快速填入对话框中。
- **纯客户端无状态：** 完全基于客户端响应式 Store 与 Cordis 插槽体系运行。
